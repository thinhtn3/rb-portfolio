# RB Portfolio

**Live version:** https://thinhtn.vercel.app

A portfolio website built with React, Vite, and Tailwind CSS.

## Run locally

Requires Node.js 18+ (npm included).

```bash
cd rb-portfolio-1
npm install
npm run dev
```

Then open the URL shown in the terminal (typically http://localhost:5173/). Press `Ctrl + C` to stop the server.

Note: the site starts with an intro animation, then a scroll-driven hero. Scroll down to reach the About, Projects, and Contact sections.
